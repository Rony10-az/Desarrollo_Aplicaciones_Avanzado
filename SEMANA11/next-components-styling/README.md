# next-components-styling

Ejercicio 1 de la Semana 11 — componentes reutilizables combinando **CSS Modules** y **Tailwind CSS**. Ver el [README general](../README.md) para el contexto completo del laboratorio.

## Componentes

- **[`Button`](src/components/ui/Button.tsx)** — variantes, tamaños, estado de carga y efecto de onda al click (CSS Modules).
- **[`Card`](src/components/cards/Card.tsx)** — título, imagen y footer opcionales (solo Tailwind).
- **[`Badge`](src/components/ui/Badge.tsx)** — variantes de color y tamaño (solo Tailwind).
- **[`Input`](src/components/ui/Input.tsx)** — label flotante y animación de error (CSS Modules).

## Ejecutar

```bash
npm install
npm run dev
```

Abre [http://localhost:3000/styling](http://localhost:3000/styling) para ver la página de demostración.
